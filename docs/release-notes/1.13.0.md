**Распред разделён на два этапа.** В боковой панели теперь два пункта вместо одного:

- **Распред · подготовка** — из инвойса и справочников собираются листы «для цен» и «Цены».
  После неё вы протягиваете колонки со стенками и согласованными ценами.
- **Распред · пересчёт** — программа проверяет протянутые колонки, сверяет с «link»
  и заполняет «остатки», «Распред» и «Загрузочник».

Раньше всё шло одним прогоном — до того, как стенки протянуты, и проверять по ним было
нечего. Каждый этап проверяет книгу до запуска только на свои листы и помнит свою папку.

**Один файл — один сектор.** В инвойсе сектор не написан: он появляется только на листе
«Цены». Если секторов оказалось несколько, нужный берётся из названия файла — «C2518-084
Бижутерия LTL719.xlsx». Хватает одного слова из названия сектора: «КОЛГОТКИ,НОСКИ»
находится по файлу «318-140 Носки FTL 36». Если по названию не решить — программа спросит.
Строки остальных секторов в файл не попадают, и «Количество» с «Суммой закупа» на листе
«для цен» считаются только по оставшимся.

**Лишняя колонка на листе «для цен» больше не остаётся.** Колонок становится ровно столько,
сколько инвойсов: недостающая создаётся копией первой — вместе с формулами «Курс»
и «% логистики», — а лишняя очищается целиком. Ссылки строк «Цены» на «для цен»
переводятся на нужную колонку в обе стороны: строка, оставшаяся от поставки с двумя
инвойсами, возвращается на первую колонку.

**Пересчёт процента сезонности.** Три месяца, как и раньше, заполняются с листа «КС».
Дальше для «БИЖУТЕРИЯ» доли двух первых месяцев пересчитываются по шаблону (4 % и 6 %
становятся 40 % и 60 %), а для «КОЛГОТКИ,НОСКИ» и «УКРАШЕНИЯ ДЛЯ ВОЛОС» — доли всех трёх.
Третий месяц бижутерии остаётся таким, как посчитался с «КС»: он справочный. Остальным
секторам пересчёт не делается.
