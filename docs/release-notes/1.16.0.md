**Распред: фотографии, наценки по подгруппам и сезонность без вопросов.**

- **Фотографии из инвойса** теперь доезжают до отчёта. Подготовка ставит их на лист «Цены»
  в колонку «артикул» — каждой строке свою, по штрихкоду. Пересчёт переносит их дальше,
  в заголовок каждого блока листа «Распред». Раньше во всех блоках оказывалась одна и та же
  картинка: размножение первого блока копировало картинку образца. Теперь старые картинки
  из области блоков удаляются, и на их место встаёт фотография своего АЦР.
- **Наценки переехали на второй этап** — туда, где им и место: к этому моменту подгруппы
  уже проставлены и видно, сколько их в поставке. Наценка берётся на каждую подгруппу своя,
  и если сектор в «Регламенте наценок» встречается несколькими строками, вопрос будет
  по каждой подгруппе отдельно. На подготовке обе колонки наценок очищаются, чтобы значения
  прошлой поставки не участвовали в расчёте цен.
- **Про сезонность программа больше не спрашивает.** Берутся три месяца подряд, начиная
  со следующего за текущим: распред делают на месяцы вперёд, а текущий уже наполовину
  прошёл. Какие месяцы взяты — написано в замечаниях.
- **Недели сезонности считаются по производственному календарю.** Первая неделя года — та,
  на которую приходится 1 января, и неделя идёт в расчёт месяца, если в этом месяце лежат
  хотя бы три её дня. По такому счёту в 2026 году 52 недели — ровно столько колонок
  и на листе «КС», — а декабрь заканчивается неделей 28 декабря, у которой номер уже
  первый. Раньше эта неделя терялась, и доля декабря выходила заниженной: 49 % вместо 62 %.

**Подтоварка МП: правила сверены с готовым отчётом.**

Программа прогнана по подтоварке, которую аналитик собрал вручную, — 432 строки. После
правок расхождений нет ни по «Заметке», ни по «в подтоварку». Что изменилось:

- **Пустой «Запрет».** Разница «Фактическое кол-во» минус «в подтоварку» теперь считается
  только там, где «Фактическое кол-во» заполнено и больше нуля: в ручной работе лист
  сначала фильтруется по непустым значениям этой колонки. Где собирать на ВБ+Озон нечего,
  решает «Прогнозный sellout». Старое правило ошибалось на 285 строках из 432.
- **Новые значения «Запрета»** — «доп согл» и «запрет, доп согл»: такие строки везём только
  после отдельного разговора, им пишется «Согласовать».
- **«УКРАШЕНИЯ ДЛЯ ВОЛОС»** добавлены к секторам, которым согласование не нужно.
- **Лист согласования называется «Согласовать»** — так же, как в готовых подтоварках.
- **Разные названия колонок.** «Запрет» может называться «Комментарий (на запрет)»,
  «Заметка» — «Заметки»; программа понимает оба варианта.
