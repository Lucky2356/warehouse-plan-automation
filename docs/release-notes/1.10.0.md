**Важно: обновиться нужно с 1.9.0.** В 1.9.0 «План склада» падал в самом конце —
книга сохранялась, но вместо карточки результата появлялась ошибка. Причина: программа
читала названия листов уже после закрытия книги. Исправлено.

**Тёмная и светлая темы.** Переключатель — маленькая кнопка внизу боковой панели.
Выбор запоминается до следующего запуска.

**Загрузочник из одной колонки.** Если в заготовке осталась единственная колонка кода
(так бывает после поставки с одним кодом), суммы по колонкам больше не съезжают:
Excel не умеет расширять диапазон из одной ячейки, и программа теперь чинит такие
формулы сама. Раньше проверка честно показывала «ЛОЖЬ», но колонки приходилось править
руками — теперь результат совпадает с обычным прогоном до ячейки.

**Пустая подсказка у курсора.** Наведение на пустое поле файла больше не показывает
пустой прямоугольник.

**Excel не остаётся в памяти** после перехода по замечанию: программа освобождает
все ссылки, и закрытое вами окно Excel действительно закрывается.

Подсказка «щёлкните по замечанию» теперь показывается только тогда, когда переход
действительно есть, а двойной щелчок по замечанию не запускает второй Excel.

Скачайте единственный `.exe` и запустите — установка и распаковка не нужны.

Требования: Windows x64 и установленный Microsoft Excel (2016 и новее, включая 2021 и 365).
Отдельная установка .NET не нужна: всё встроено в файл.
