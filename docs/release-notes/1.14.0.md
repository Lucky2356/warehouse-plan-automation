**Имя файла говорит, что с книгой сделали.** Вместо «\_готово\_» к имени добавляется
название этапа:

```
Поставка 431-329 подготовка 2026-09-09_1550.xlsx
Поставка 431-329 распред 2026-09-09_1552.xlsx
Plan_sklada_03_09 план склада 2026-09-09_1550.xlsx
```

Отметка прошлого запуска снимается, поэтому после двух этапов распреда имена больше
не накапливаются: файл второго этапа называется «… распред …», а не «… подготовка …
распред …». Старые файлы с «готово» тоже переименовываются начисто.

**Окно выбора приведено к теме приложения.** Список вариантов рисовался стандартным
списком Windows: системный синий вместо акцента и системный цвет текста, который
на тёмном фоне почти не читался. Теперь выбранный вариант виден сразу тремя признаками —
закрашенный кружок, подложка акцентом и более яркий и жирный текст, — а заголовок окна
красится в цвет темы, как у главного окна.

Тёмная тема для заголовка теперь определяется по самому фону окна, а не по настройке:
так заголовок не может разойтись с палитрой, которая на окне на самом деле.
